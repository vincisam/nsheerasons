# Quick Start: Connect GitHub to Railway

Your backend is live at `https://nsheera-rates-proxy-production.up.railway.app`. Now connect GitHub Actions to automate deployments and set up the AI Design Studio.

## ⚡ 5-Minute Checklist

- [ ] **1. Get Anthropic API Key**
  - Go to https://console.anthropic.com → API keys → Create new key
  - Copy the key

- [ ] **2. Get Railway API Token**
  - Go to https://railway.app → Profile (top-right) → Account → API Tokens
  - Click **Create** and copy the token

- [ ] **3. Get Railway Project ID**
  - In Railway dashboard, open your project
  - Click Settings (gear icon) → Copy the **Project ID**

- [ ] **4. Add GitHub Secrets**
  - Go to GitHub → Your repo → Settings → Secrets and variables → Actions
  - Click **New repository secret** for each:
    - `RAILWAY_TOKEN` = (your token from step 2)
    - `RAILWAY_PROJECT_ID` = (your project ID from step 3)
    - `ANTHROPIC_API_KEY` = (your Anthropic key from step 1) ← **NEW**
    - `METALS_API_KEY` = `UWY1VV6WCDIKUEG1YNEP476G1YNEP`
    - `FRONTEND_URL` = `https://vincisam.github.io/nsheera/`
    - `RATES_BACKEND_URL` = `https://nsheera-rates-proxy-production.up.railway.app/api/rates`

- [ ] **5. Push to main**
  - Commit your changes and push to `main`
  - Both workflows will trigger automatically

- [ ] **6. Verify**
  - GitHub → Actions tab → Both workflows should turn green
  - Frontend live at https://vincisam.github.io/nsheera/
  - AI Design Studio now works! (Admin can test it)

**✨ Done! Your CI/CD is now fully live with AI Design Studio enabled.**
